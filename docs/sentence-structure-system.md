# Japanese Sentence Structure — 7-Block Model (Implementation Table)

| # | Block Name                         | Symbol | What It Includes                                 | Examples                         |
|---|------------------------------------|--------|--------------------------------------------------|----------------------------------|
| 1 | Noun Block                         | 🟦     | Nouns, noun phrases, な-adjectives (use な before nouns) | 学生、きれいな人、日本語           |
| 2 | Verb Block                         | 🟩     | Verb base forms; い-adjectives (same conjugation family) | 行く／行った／行かない、さむい     |
| 3 | Particles                          | 🟧     | が、は、を、に、で、へ、も、から、まで、や、とか、など | 日本語を話す                      |
| 4 | Sentence-End Block (Auxiliaries)   | 🟥     | ます、です、たい、ない、そう、でしょう、よ、ね、かな、てください | 行きます、行きたいです            |
| 5 | Functional Words                   | 🟪     | Connective / structural words                   | とき、から、ので、けど、ために、ように、ところ |
| 6 | Context Words                      | 🟨     | Time / degree / frequency / stance words        | さいきん、すぐ、よく、ほんとうに   |
| 7 | Fixed Expressions                  | 🟫     | Set phrases treated as one unit                 | よろしくお願いします、すみません     |
